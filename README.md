A tiny Python program that writes one short text to `/output/entry.txt` for
the [make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

Run it with Python 3.13 (stdlib only, no network):

```bash
python3 main.py
```

It writes the entry text to `/output/entry.txt` when that directory exists,
otherwise to `./output/entry.txt`.
